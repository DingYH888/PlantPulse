# 通用养护：土壤、换盆与根系护理

## 概述

介质是根系的生存环境，决定了水分、空气与养分的平衡。换盆不是每年必做的任务，而是根据根系状态与介质老化程度决定的干预。理解介质配比与根系健康，可以从根本上减少烂根与黄叶。

## 常见介质的作用

泥炭与腐叶土保水保肥，是多数配土的基础；珍珠岩与粗砂增加排水与透气，防止板结；椰糠保水但需注意盐分；树皮适合兰花与附生植物，提供大孔隙；赤玉土、鹿沼土、火山岩等颗粒适合多肉与盆景，排水性好且不易粉化；水苔保水性强，常用于兰花与扦插。没有一种介质适合所有植物，配比应根据植物习性调整。

## 配土的基本原则

通用观叶植物可用泥炭或腐叶土 5 份、珍珠岩 3 份、树皮或椰糠 2 份。多肉与仙人掌需将颗粒比例提高到 60%~80%，如赤玉土、粗砂、火山岩混合少量泥炭。兰花类使用树皮、水苔、陶粒等粗颗粒，忌用园土。喜酸植物可在介质中加入松针土，并避免使用含石灰的材料。所有配土都应保证浇水后水能迅速从盆底流出。

## 何时需要换盆

出现以下情况时应考虑换盆：根系从排水孔伸出或盘绕在盆土表面；浇水后水迅速流走，说明介质已板结、保水性下降；植株生长明显停滞，施肥后无改善；介质表面出现白色盐霜或霉斑；根系腐烂需要修根。一般而言，观叶植物每 1~2 年换盆一次，多肉每 2~3 年一次，生长缓慢的品种可更久。

## 换盆的正确步骤

换盆前 1~2 天浇一次透水，让介质与根系结合，便于脱盆。新盆直径比原盆大 3~5 厘米即可，过大盆土不易干，反而增加烂根风险。脱盆后轻轻抖散旧土，检查根系：剪除发黑、发软、空心的烂根，保留健康白根。烂根伤口可用多菌灵处理，晾干 1~2 小时再上盆。上盆时先放少量新介质，调整植株高度，填土压实但不要过度按压，浇一次透水后放在阴凉通风处缓苗。

## 缓苗期管理

换盆后 1~2 周为缓苗期，应放在散射光处，避免强光直射。缓苗期不施肥，浇水保持介质微润即可，不要频繁补水。出现少量落叶属于正常应激，不必过度干预。新叶开始生长后，逐步恢复正常光照与水肥。大型盆栽换盆后可适当修剪部分枝叶，减少蒸腾压力。

## 根系健康的判断

健康根系通常呈白色或浅褐色、质地饱满有弹性。发黑、发软、有酸臭味的根系为腐烂；干瘪易断的为失水；盘绕成团的说明盆土空间不足。定期检查根系，比等到叶片发黄再处理更有效。浇水过多、介质板结、盆底无排水孔，是根系腐烂的三大主因。
