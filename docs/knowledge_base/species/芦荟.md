# 芦荟养护指南

## 概述

芦荟是阿福花科多年生肉质植物，叶片肥厚多汁、边缘带齿，喜光耐旱。它依靠叶片储水，在干燥环境中生存力强，但怕低温和积水。家庭养护常用于观赏与取用叶汁，需注意只有可食用品种才适合外用或食用。

## 浇水

遵循"干透浇透"，春秋 10~15 天一次，夏季 7~10 天一次，冬季 20~30 天一次甚至断水。判断依据是盆土完全干燥、叶片略微软化但未皱缩。浇水时沿盆边缓慢注入，避免水积在叶腋。芦荟叶片发软透明、基部变褐是浇水过多的典型信号，应立即停水并检查根系。

## 光照

芦荟喜充足光照，每天 4~6 小时直射或强散射光最利于叶片饱满。南向、西向窗台较为合适。夏季正午极端强光可能让叶片泛红、出现日灼斑，可适当遮阴三成。长期放在室内阴暗处会徒长，叶片变薄变窄、株型松散，需逐步移到光照处，避免一次暴晒。

## 施肥

生长季 4~9 月每 2~3 个月施一次稀薄复合肥或仙人掌专用肥，浓度取推荐量的三分之一。芦荟需肥量很低，浓肥会造成根系烧伤和叶片焦尖。冬季、低温期及新换盆后一个月内不施肥。介质本身含有少量养分时，可进一步降低施肥频率。

## 温度与湿度

适宜温度 15~30℃，低于 10℃ 停止生长，低于 5℃ 叶片会冻伤透明化。芦荟喜干燥空气，湿度 30%~50% 即可，不需要喷雾，高湿反而增加腐烂风险。冬季应移入室内向阳处，保持盆土干燥以提高抗寒能力。夏季高温时加强通风，避免闷热环境。

## 病虫害防治

根腐是最主要问题，由浇水过多和介质不透气引起，需脱盆剪除烂根、晾干伤口后换颗粒介质重栽。介壳虫常附着在叶背与叶腋，少量时用酒精棉签擦除，严重时按说明使用吡虫啉。叶斑病表现为褐色凹陷斑，多因低温高湿，应剪除病叶并改善通风。

## 换盆与繁殖

每 1~2 年在春季换盆一次，盆径比原盆大 2~3 厘米，介质以颗粒土为主，如赤玉土、粗砂混合少量泥炭。基部萌生的侧芽带根后可分离另行栽种，分离后晾干伤口 1~2 天再上盆。
