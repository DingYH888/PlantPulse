# 豆瓣绿养护指南

## 概述

豆瓣绿是胡椒科多年生常绿草本，叶片厚实圆润、革质有光泽，株型小巧，适合桌面摆放。它耐旱性较强、喜半阴，属于好养的耐阴植物。肉质叶片储水，最怕浇水过勤导致烂茎，也怕强光灼伤。

## 浇水

表土干燥 2~3 厘米后浇透，春秋 7~10 天一次，夏季 5~7 天一次，冬季 15~20 天一次。豆瓣绿叶片厚实，缺水时略微软化，浇水后可恢复。盆土长期潮湿会导致茎基发黑腐烂，因此宁干勿湿。浇水沿盆边注入，避免水积在叶腋。托盘积水需及时倒掉。

## 光照

喜明亮散射光，东向窗、北向窗或距南窗 2 米处均可，每天 3~5 小时柔和光照。夏季避开正午直射，强光会让叶片出现褐色灼斑。长期过暗则枝条徒长、叶片变小、叶色变浅。斑叶品种需要稍多光照以维持花纹，但同样避免暴晒。

## 施肥

生长季 4~9 月每 3~4 周施一次稀薄复合肥，浓度取推荐量的三分之一到一半。豆瓣绿需肥量低，浓肥易烧根并导致叶缘焦枯。冬季低于 15℃ 时停肥。新换盆植株一个月内不施肥，等新叶展开后再补充。施肥后可用清水透灌一次，减少盐分积累。

## 温度与湿度

适宜温度 18~28℃，低于 12℃ 生长放缓，低于 8℃ 易受寒害、叶片发黑。空气湿度 50%~70% 较合适，干燥季节可喷雾周围空气，但避免叶面长期积水。冬季应放在温暖处，远离冷窗与出风口。温度骤降会导致下部叶片软腐脱落。

## 病虫害防治

根腐与茎腐是最常见问题，多由浇水和介质不透气引起，需脱盆剪除腐烂部分、消毒后换颗粒比例较高的介质。叶斑病表现为叶片褐色斑点，应剪除病叶、改善通风。介壳虫少量时用酒精棉签清除即可。定期擦拭叶片可保持光泽并及早发现虫害。

## 繁殖与换盆

枝插或叶插均可，取健康茎段保留 2~3 个节点插入湿润介质，约 2~3 周生根。每 1~2 年春季换盆一次，盆不宜过大，介质需疏松透气，可用泥炭混合珍珠岩。盆过大时土壤不易干，反而增加烂根风险。
