# 袖珍椰子养护指南

## 概述

袖珍椰子是棕榈科常绿小灌木，羽状小叶排列整齐，株型小巧，耐阴性强，适合桌面与室内角落摆放。它喜温暖高湿和散射光，怕强光、怕积水、怕冷风。相比大型棕榈，袖珍椰子生长缓慢，养护得当可多年保持翠绿。

## 浇水

表土干燥 1~2 厘米后浇透，春秋 4~6 天一次，夏季 2~3 天一次，冬季 7~10 天一次。袖珍椰子根系细密，既不耐旱也不耐涝，介质应保持均匀微润。浇水后及时倒掉托盘积水。空气干燥时可向叶面喷雾，但避免叶心长期积水。水质含盐高时叶尖易枯，建议使用放置过的自来水。

## 光照

喜半阴散射光，北向窗、东向窗或距南窗 2~3 米处较理想，每天 2~4 小时柔和光照即可。强光直射会让叶片发黄、叶尖焦枯。长期放在阴暗处虽能存活，但新叶细弱、叶色变浅、生长停滞。可每 2 周转动花盆一次，让受光均匀。

## 施肥

生长季 4~9 月每 2~3 个月施一次稀薄棕榈专用肥或复合肥，浓度取推荐量的三分之一。袖珍椰子需肥量低，浓肥易导致叶尖焦枯。冬季低于 15℃ 时停肥。新换盆植株两个月内不施肥。施肥后可轻浇一次清水，减少盐分积累。

## 温度与湿度

适宜温度 18~28℃，低于 12℃ 生长停滞，低于 8℃ 易受寒害。空气湿度 60%~80% 较理想，干燥季节需喷雾或使用加湿器，否则叶尖容易干枯。冬季远离冷窗、门口与暖气片。注意避免空调冷风直吹，否则叶片会迅速失水发黄。

## 病虫害防治

叶尖焦枯是最常见问题，多因空气干燥、水质偏硬或施肥过量，可修剪干尖、改用放置过的水并提高湿度。根腐由积水引起，需控水、脱盆修根并换透气介质。红蜘蛛与介壳虫偶发，少量时人工清除，严重时按说明使用对应药剂。

## 换盆与养护

每 2 年春季换盆一次，盆不宜过大，介质需疏松保水且排水良好。袖珍椰子根系较浅，盆过大时土壤不易干，反而增加烂根风险。换盆后放阴凉通风处缓苗两周，期间避免强光与施肥。下部老叶自然枯黄时可从基部剪除。
