# 栀子花养护指南

## 概述

栀子花是茜草科常绿灌木，叶片浓绿光亮、花朵洁白浓香，夏季开花。它喜酸性土壤、充足光照和较高湿度，是典型的"喜酸植物"。栀子花最常见的失败是土壤碱化导致黄叶，以及花蕾期环境变动导致落蕾。

## 浇水

表土干燥 1~2 厘米后浇透，春秋 2~3 天一次，夏季每天一次，冬季 5~7 天一次。栀子花喜湿润，但忌积水，盆底排水必须通畅。建议使用雨水、纯净水或放置过的自来水，减少土壤碱化。每月浇一次稀释的硫酸亚铁溶液，维持微酸性环境。夏季可向周围喷雾增湿。

## 光照

喜充足散射光，每天 4~6 小时柔和光照有利于花芽分化与开花。春秋可接受早晚直射，夏季需遮阴 40%~50%，强光会让叶片发黄、花蕾灼伤。冬季放在南向窗台充分见光。光照不足会导致枝条徒长、开花稀少。

## 施肥

生长季每 10~15 天施一次稀薄酸性液肥，浓度取推荐量的一半。现蕾期改用磷钾肥，减少氮肥比例，避免只长叶不开花。每月补充一次硫酸亚铁，预防缺铁黄化。夏季高温超过 35℃ 与冬季低于 10℃ 时停肥。忌施碱性肥料与未腐熟有机肥。

## 温度与湿度

适宜温度 18~25℃，高于 32℃ 生长受阻、花蕾易脱落，低于 5℃ 易受冻害。空气湿度 60%~80% 较理想，干燥季节需喷雾增湿，但避免花朵沾水。花蕾期避免频繁移动花盆与温度骤变，否则容易落蕾。冬季移入室内向阳处，保持 8℃ 以上。

## 病虫害防治

黄化病多因土壤碱化缺铁，表现为新叶叶脉绿、叶肉黄，需补充硫酸亚铁并改用酸性水。叶斑病在通风不良时易发，应摘除病叶、减少叶面淋水。介壳虫与红蜘蛛常见，少量时人工清除，严重时按说明使用对应药剂。花蕾期谨慎喷药，避免药害导致落蕾。

## 修剪与换盆

花后剪除残花与过密枝，促进通风与新枝萌发。春季可短截徒长枝，保持株型。每 1~2 年春季换盆一次，介质必须微酸性、疏松透气，可用腐叶土混合松针土与珍珠岩。换盆时避免伤根过多，缓苗期间遮阴并保持湿度。
