# 石斛养护指南

## 概述

石斛是兰科附生植物，茎节明显、花色丰富，部分品种兼具观赏与药用价值。它喜明亮散射光、高湿和良好通风，根系需透气介质。石斛的栽培方式与蝴蝶兰相近，可用树皮、水苔或附石栽培，忌用普通园土。

## 浇水

介质干透后浇透，春秋 5~7 天一次，夏季 2~3 天一次，冬季 10~15 天一次。石斛喜湿润但怕积水，浇水后必须让多余水分流出。空气干燥时可每日喷雾增湿，但避免叶心与茎节长期积水。冬季低温时应减少浇水，保持介质偏干，有利于花芽分化。

## 光照

喜明亮散射光，每天 4~5 小时柔和光照较理想。东向窗、南向窗加纱帘均可。光照不足会导致茎秆细弱、不开花；强光直射会让叶片与茎秆灼伤发黄。夏季需遮阴 50% 左右，冬季可适当增加光照。定期转动花盆，避免偏向生长。

## 施肥

生长季每 2~3 周施一次稀薄兰花专用肥，浓度取推荐量的四分之一到三分之一。新芽生长期偏氮，花芽分化期改用磷钾肥。花期与冬季低温时停肥。施肥后用清水冲洗介质，防止盐分积累。附石或附树皮栽培时，可结合叶面肥补充养分。

## 温度与湿度

适宜温度白天 20~28℃、夜间 15~20℃。低于 10℃ 生长停滞，部分品种可耐短期 5℃；高于 32℃ 需加强通风降温。空气湿度 60%~80% 较理想，干燥季节需喷雾或使用加湿器。冬季适度低温与控水有助于花芽形成。避免冷风直吹。

## 病虫害防治

根腐多由介质积水与透气不良引起，需脱盆剪除烂根、消毒后换新介质。软腐病与黑斑病在高温高湿时易发，表现为茎叶出现水渍状或黑色病斑，应切除病部、隔离植株并改善通风。介壳虫与红蜘蛛常见，少量时人工清除，严重时按说明使用低浓度药剂。

## 换盆与繁殖

每 1~2 年春季换盆一次，介质以树皮、水苔、火山石为主，保证透气排水。换盆时剪除空根与烂根，重新固定后缓苗两周。石斛可通过分株繁殖，将带 3~4 个假鳞茎的株丛分开，晾干伤口后另行栽种。
