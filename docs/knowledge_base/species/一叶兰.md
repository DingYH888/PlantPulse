# 一叶兰养护指南

## 概述

一叶兰是天门冬科多年生常绿草本，叶片宽大挺拔、深绿有光泽，极耐阴、耐旱、耐粗放管理。它是少数能在光线较弱室内长期存活的观叶植物，适合走廊、办公室等光照不足的位置。养护难点少，主要是避免积水与冬季低温。

## 浇水

表土干燥 3~5 厘米后浇透，春秋 7~10 天一次，夏季 5~7 天一次，冬季 15~20 天一次。一叶兰根状茎储水，耐旱能力强，盆土偏干问题不大，积水却容易导致根茎腐烂。浇水后倒掉托盘积水并通风。冬季低温时应进一步控水，保持介质偏干。

## 光照

耐阴性强，明亮散射光到较弱光线均可，北向窗、走廊、室内角落都能适应。每天 2~4 小时柔和光照即可，光照过强反而会让叶片发黄、叶缘焦枯。长期完全无光时生长缓慢但不易死亡。若希望新叶更茂盛，可放在有散射光的窗边。

## 施肥

生长季 4~9 月每 1~2 个月施一次稀薄复合肥，浓度取推荐量的一半。一叶兰需肥量低，施肥过勤会导致叶片徒长、叶色过淡。冬季及低温期停肥。新换盆植株两个月内不施肥，等根系稳定后再补充。

## 温度与湿度

适宜温度 15~25℃，可耐受短期 5℃ 低温，低于 5℃ 叶片会出现冻斑。空气湿度 40%~60% 即可，对干燥环境容忍度高，不需要频繁喷雾。冬季应放在避风处，避免冷风直吹。夏季高温时保持通风，减少浇水频率。

## 病虫害防治

根腐与根茎腐烂是最常见问题，多由浇水过多和排水不良引起，需脱盆剪除腐烂部分、消毒后换透气介质。叶斑病表现为叶片褐色斑点，多因通风不良，应剪除病叶并改善环境。介壳虫偶有发生，常附着在叶背与叶柄，少量时用酒精棉签清除即可。

## 换盆与分株

每 2~3 年春季换盆一次，盆径增加 3~5 厘米，介质需疏松排水，可用园土混合珍珠岩。根状茎密集时可分株，每丛保留 3~5 片叶与完整根系，分株后放阴凉处缓苗两周再正常养护。
