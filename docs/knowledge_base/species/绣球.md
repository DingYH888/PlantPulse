# 绣球养护指南

## 概述

绣球是绣球花科落叶灌木，花序球形、花量大，是夏季代表性花卉。它喜半阴、喜湿润、喜肥，不耐强光与干旱。部分品种的花色会随土壤酸碱度变化，酸性土壤偏蓝、碱性土壤偏粉，调色需在花芽分化前开始。

## 浇水

绣球叶片大、蒸腾强，需保持介质湿润，表土略干即补水，春秋 1~2 天一次，夏季每天一次甚至早晚各一次，冬季 5~7 天一次。缺水时叶片会迅速萎蔫，但补水后多能恢复。盆底排水必须通畅，忌长期积水。夏季高温时可在早晚浇水，避免正午。

## 光照

喜半阴散射光，每天 3~5 小时柔和光照较理想。春秋可接受早晚直射，夏季需遮阴 50%~70%，强光会让叶片焦边、花朵褪色。光照过弱会导致枝条徒长、花芽少。盆栽可放在东向阳台或树荫下。花期避免暴雨冲刷与强风。

## 施肥

生长季每 2 周施一次稀薄复合肥，浓度取推荐量的一半，萌芽期偏氮，现蕾期改用磷钾肥。调蓝品种可在春季使用硫酸铝溶液，每 2~3 周一次，同时保持土壤酸性。夏季高温与冬季休眠期停肥。忌浓肥，容易烧根。

## 温度与湿度

适宜温度 18~25℃，高于 32℃ 生长受阻、花朵易焦，低于 5℃ 进入休眠。空气湿度 60%~80% 较合适，干燥季节可喷雾增湿。冬季需经历低温休眠，来年花芽更饱满。盆栽越冬应放在避风处，减少浇水但不可完全干透。

## 病虫害防治

叶斑病与白粉病在通风不良时易发，表现为叶片斑点或白色粉层，需摘除病叶、改善通风并定期喷施保护性杀菌剂。红蜘蛛在干燥环境易发，需提高湿度并喷洒杀螨剂。蚜虫聚集在嫩梢，可用清水冲洗。夏季暴雨后应及时排水，防止根腐。

## 修剪与调色

多数大花绣球在老枝上开花，修剪应在花后立即进行，避免剪除来年花芽。无尽夏等新老枝兼开花品种可在冬季重剪。调蓝需在花芽分化前（春季）开始，持续使用酸性介质与硫酸铝；调粉则使用石灰或碱性介质。调色效果受品种与水质影响。
