# 月季养护指南

## 概述

月季是蔷薇科灌木，花期长、花色丰富，可分灌木月季、藤本月季与微型月季。它喜充足光照和良好通风，是典型的"喜光喜肥"花卉。月季养护的核心是光照、施肥与病虫害预防，尤其要重视黑斑病与红蜘蛛的早期防治。

## 浇水

表土干燥 2~3 厘米后浇透，春秋 3~5 天一次，夏季 1~2 天一次，冬季 7~10 天一次。月季喜湿润但不耐涝，盆栽需保证排水通畅，托盘积水及时倒掉。浇水应浇在盆土上，避免长期淋湿叶片，以减少黑斑病发生。夏季高温时早晚浇水，避开正午。

## 光照

喜充足直射光，每天至少 5~6 小时，南向阳台或露台最理想。光照不足会导致枝条细弱、花蕾少、花色淡、病害增多。夏季正午极端高温时可适当遮阴，减少花朵灼伤。通风良好能显著降低病害发生率，盆栽之间应留有间距。

## 施肥

生长季每 7~10 天施一次稀薄液肥，萌芽期偏氮，现蕾期改用磷钾肥。花后补一次复合肥帮助恢复。可使用缓释肥作为底肥，减少追肥频率。夏季高温超过 35℃ 与冬季休眠期停肥。施肥前盆土应微湿，避免干土施肥烧根。

## 温度与湿度

适宜温度 15~26℃，高于 33℃ 开花减少、花朵变小，低于 5℃ 进入休眠。空气湿度 50%~70% 较合适，湿度过高且通风不良时黑斑病高发。冬季需经历一段低温休眠，来年开花更整齐。盆栽越冬应放在避风向阳处，减少浇水。

## 病虫害防治

黑斑病是最常见病害，叶片出现黑色斑点并黄化脱落，需及时摘除病叶、避免叶面淋水、改善通风，并定期喷施保护性杀菌剂。白粉病表现为叶面白色粉层，可改善通风并使用对症药剂。蚜虫聚集在嫩梢与花蕾，可用清水冲洗或按说明用药。红蜘蛛在干燥环境易发，需提高湿度并定期检查叶背。

## 修剪与换盆

花后在花下 2~3 片叶处剪除残花，促进新枝与二次开花。冬季休眠期进行重剪，去除病弱枝、交叉枝，保留健壮主枝。每 1~2 年春季换盆一次，介质需疏松肥沃、排水良好，可加入腐熟有机肥作底肥。
