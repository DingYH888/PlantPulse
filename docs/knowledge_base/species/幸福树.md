# 幸福树养护指南

## 概述

幸福树是紫葳科常绿小乔木，叶片细小浓密、株型丰满，寓意美好，是常见的室内中型绿植。它喜温暖湿润和明亮散射光，生长较快。幸福树最常见的失败是浇水过勤导致烂根，以及环境突变引起的大量落叶。

## 浇水

表土干燥 3~4 厘米后浇透，春秋 7~10 天一次，夏季 5~7 天一次，冬季 15~20 天一次。幸福树根系较发达但不耐涝，盆土应保持见干见湿。浇水后倒掉托盘积水并通风。空气干燥时可喷雾叶面，但不能代替浇水。叶片突然大量脱落时，先检查盆土是否长期过湿。

## 光照

喜明亮散射光，距南向窗 1~2 米或东向窗边最佳，每天 4~5 小时柔和光照。夏季避开正午直射，防止叶片焦枯。长期放在阴暗处会导致枝条细弱、叶片稀疏、下部大量落叶。每 2 周转动花盆一次，保持株型匀称。位置固定后尽量减少搬动。

## 施肥

生长季 4~9 月每 2~3 周施一次均衡复合肥，浓度取推荐量的一半。幸福树生长快，需肥量中等，但浓肥会造成叶缘焦枯与根系损伤。秋季补施磷钾肥提高抗性。冬季低于 15℃ 时停肥。新购或换盆后一个月内不施肥。

## 温度与湿度

适宜温度 20~30℃，低于 12℃ 生长受阻，低于 8℃ 易落叶与冻伤。空气湿度 55%~75% 较合适，供暖季与空调房应定期喷雾或使用加湿器。冬季远离冷风窗口与门口。温度骤变、冷风直吹是造成突然落叶的主要原因。

## 病虫害防治

根腐与茎腐多由浇水过多引起，表现为叶片发黄脱落、茎基变软，需脱盆剪除腐烂部分并换透气介质。叶斑病在通风不良时易发，应剪除病叶、减少叶面淋水。介壳虫与红蜘蛛偶发，少量时人工清除，严重时按说明用药。定期冲洗叶片可减少虫害。

## 修剪与换盆

徒长枝、过密枝可从基部剪除，改善通风并保持株型。每 1~2 年春季换盆一次，盆径增加 3~5 厘米，介质需疏松透气。换盆后放阴凉通风处缓苗一周，期间减少浇水，等新叶稳定后再恢复正常养护。
