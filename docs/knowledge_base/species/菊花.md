# 菊花养护指南

## 概述

菊花是菊科多年生草本，品种繁多、花期集中在秋季，是传统名花。它喜充足光照、凉爽环境和良好通风，是典型的短日照植物。菊花养护的关键是摘心整形、充足光照与花芽分化期的短日照管理。

## 浇水

表土干燥 2~3 厘米后浇透，春秋 2~3 天一次，夏季每天一次，冬季 5~7 天一次。菊花喜湿润但怕积水，盆底排水必须通畅。浇水应浇在盆土上，避免长期淋湿叶片，减少病害。夏季高温时早晚浇水，避开正午。现蕾期保持水分稳定，忽干忽湿容易落蕾。

## 光照

喜充足光照，每天 5~6 小时直射光有利于株型紧凑与开花。菊花是短日照植物，秋季日照缩短时自然形成花芽。若希望提前开花，可每天给予 8~10 小时光照、其余时间遮光，持续数周。光照不足会导致枝条徒长、花蕾少、花色淡。夏季强光时适当遮阴。

## 施肥

生长季每 7~10 天施一次稀薄液肥，浓度取推荐量的一半，前期偏氮促进枝叶，现蕾后改用磷钾肥。盆栽可结合浇水追肥。夏季高温超过 35℃ 时停肥。开花期停肥，避免花朵早谢。花后补一次薄肥帮助恢复。忌浓肥与生肥。

## 温度与湿度

适宜温度 15~25℃，高于 32℃ 生长受阻，低于 5℃ 地上部分逐渐枯萎。空气湿度 50%~70% 较合适，高湿不通风时易发白粉病与黑斑病。夏季需加强通风降温。冬季可剪除枯枝，保留根部越冬，来年春季重新萌发。避免冷风直吹花朵。

## 病虫害防治

白粉病与黑斑病是最常见病害，表现为叶面白色粉层或黑色斑点，需摘除病叶、改善通风并定期喷施杀菌剂。蚜虫聚集在嫩梢与花蕾，可用清水冲洗或按说明用药。红蜘蛛在干燥环境易发，需提高湿度并喷洒杀螨剂。避免叶面长期积水，可显著降低发病率。

## 摘心与整形

幼苗长到 10~15 厘米时进行第一次摘心，促进分枝；侧枝长到 8~10 厘米时可再次摘心，一般摘心 2~3 次，最后一次应在花芽分化前完成。及时去除侧蕾可使主蕾更大。花后剪除残花与枯枝，减少养分消耗。每 1~2 年春季换盆一次，介质需疏松肥沃。
