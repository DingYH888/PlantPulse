# 蟹爪兰养护指南

## 概述

蟹爪兰是仙人掌科附生植物，茎节扁平如蟹爪，冬春在茎节顶端开花，花色鲜艳。它原产热带雨林树干上，喜散射光与较高湿度，与沙漠型仙人掌习性不同。养护关键是排水良好、避免茎节积水、秋季短日照促花。

## 浇水

表土干燥 2~3 厘米后浇透，春秋 5~7 天一次，夏季高温半休眠时 7~10 天一次且减少水量，冬季开花期 7~10 天一次。蟹爪兰根系细弱，怕积水与浓肥。浇水沿盆边注入，避免水积在茎节连接处。托盘积水必须倒掉。花期保持介质微润，过干会导致落蕾。

## 光照

喜明亮散射光，东向窗、北向窗或距南窗 1~2 米处较合适，每天 3~5 小时柔和光照。夏季需遮阴 50% 以上，强光会让茎节发红、灼伤。秋季为短日照植物，每天给予 8~10 小时光照、其余时间遮光，约 6~8 周形成花蕾。冬季开花期避免频繁移动。

## 施肥

生长季 4~6 月与 9~10 月每 2~3 周施一次稀薄复合肥，浓度取推荐量的三分之一到一半。现蕾期改用磷钾肥促进花苞发育。夏季高温与冬季花期停肥，花期施肥容易导致落蕾。新换盆植株一个月内不施肥。

## 温度与湿度

适宜温度 15~25℃，高于 30℃ 进入半休眠，低于 10℃ 生长停滞。花芽分化期以 12~15℃ 为宜，温度过高会影响成花。空气湿度 50%~70% 较合适，干燥季节可喷雾周围空气，但避免茎节积水。冬季远离冷窗与暖气片。

## 病虫害防治

茎腐与根腐多由浇水过多、介质不透气引起，表现为茎节发软透明、有异味，需立即脱盆剪除腐烂部分、消毒晾干后换透气介质。介壳虫常附着在茎节缝隙，少量时用酒精棉签清除，严重时按说明使用吡虫啉。红蜘蛛在干燥环境易发，可提高湿度并喷洒杀螨剂。

## 修剪与换盆

花后剪除残花与过长的茎节，每枝保留 2~3 节，可促进分枝与来年开花。茎节过密时疏剪改善通风。每 1~2 年春季花后换盆一次，介质需疏松透气，可用泥炭混合珍珠岩与树皮。换盆后放阴凉处缓苗一周。
