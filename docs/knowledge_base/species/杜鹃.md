# 杜鹃养护指南

## 概述

杜鹃是杜鹃花科常绿或半常绿灌木，花量极大、色彩丰富，是传统名花。它喜酸性土壤、半阴高湿环境，根系为细密须根，怕旱怕涝、怕碱怕浓肥。杜鹃养护难度较高，核心是酸性介质、稳定湿度与避免环境剧变。

## 浇水

保持介质微润，表土略干即补水，春秋 2~3 天一次，夏季每天一次，冬季 5~7 天一次。杜鹃根系细弱，既不能干透也不能积水。建议使用雨水或放置过的自来水，避免碱性水。浇水应细水慢浇，确保介质充分吸水。托盘积水需及时倒掉。空气干燥时喷雾增湿。

## 光照

喜半阴散射光，东向窗、北向窗或距南窗 2 米处较合适，每天 2~4 小时柔和光照。强光直射会灼伤叶片，导致焦边与落叶。光照过弱则枝条细弱、花芽少、花色淡。夏季需遮阴 60% 以上，冬季可适当增加光照。花期避免频繁移动位置。

## 施肥

生长季每 2~3 周施一次稀薄酸性液肥，浓度取推荐量的三分之一到一半。现蕾期改用磷钾肥。忌施碱性肥料、浓肥与未腐熟有机肥。每月可补充一次硫酸亚铁维持酸性。夏季高温与冬季低温时停肥。新换盆植株一个月内不施肥。

## 温度与湿度

适宜温度 15~25℃，高于 30℃ 生长受阻，低于 5℃ 易受冻害。空气湿度 65%~85% 是理想区间，干燥环境会导致叶片焦边、花蕾脱落。可通过加湿器、湿石子托盘增湿。花期避免温度剧烈波动与冷风直吹。冬季移入室内，保持 5℃ 以上并控水。

## 病虫害防治

黄化病多因土壤偏碱缺铁，需补充硫酸亚铁并改用酸性水。叶斑病与褐斑病在高温高湿不通风时易发，应摘除病叶、改善通风并减少叶面淋水。红蜘蛛在干燥环境易发，可提高湿度并喷洒杀螨剂。杜鹃对药剂敏感，用药浓度应低于说明值。

## 修剪与换盆

花后剪除残花与过密枝，促进通风与新枝生长。重剪应在春季花后进行，避免影响来年花芽。每 1~2 年花后换盆一次，介质必须酸性、疏松透气，可用泥炭混合松针土与珍珠岩。换盆时尽量保留原土球，避免伤根过多。
