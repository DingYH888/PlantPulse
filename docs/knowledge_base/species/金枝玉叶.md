# 金枝玉叶养护指南

## 概述

金枝玉叶是刺戟木科肉质灌木，茎干红褐、叶片小巧圆润，生长快、易造型，常用于盆景式栽培。它喜光、耐旱、耐修剪，是较容易上手的多肉型观叶植物。养护重点是充足光照、严格控水与定期修剪，缺光会迅速徒长失去形态。

## 浇水

遵循"干透浇透"，春秋 7~10 天一次，夏季 5~7 天一次，冬季 15~20 天一次。金枝玉叶叶片与茎干储水，耐旱性强，盆土长期潮湿会导致烂根与落叶。浇水后及时排空托盘。夏季高温闷热时适当控水，加强通风。冬季低温时保持介质偏干，提高抗寒能力。

## 光照

喜充足光照，每天 4~6 小时直射光最理想，南向窗台或阳台均可。光照充足时茎干紧凑、叶片小而密、节间短，适合造型。光照不足会迅速徒长，节间拉长、叶片稀疏、枝条细软。夏季极端高温时正午可稍遮阴，防止叶片灼伤。定期转动花盆保持匀称。

## 施肥

生长季 4~9 月每 3~4 周施一次稀薄复合肥，浓度取推荐量的三分之一到一半。氮肥不宜过多，否则枝条徒长、叶片变大。秋季补一次磷钾肥增强抗性。冬季低于 12℃ 时停肥。新上盆或重剪后一个月内不施肥。

## 温度与湿度

适宜温度 18~30℃，低于 10℃ 生长放缓，低于 5℃ 易冻伤落叶。空气湿度 40%~60% 即可，不需要喷雾。冬季应移入室内向阳处并控水。夏季高温时加强通风，避免闷热环境。避免冷风直吹与温度骤变，否则容易大量落叶。

## 病虫害防治

根腐多由浇水过多与介质不透气引起，需脱盆剪除烂根、晾干后换颗粒介质。介壳虫常藏在枝干缝隙与叶背，少量时用酒精棉签清除，严重时按说明使用吡虫啉。蚜虫在嫩梢聚集时可用清水冲洗。通风不良时偶发叶斑，需及时摘除病叶。

## 修剪与造型

金枝玉叶耐修剪，生长期可随时短截徒长枝，促进分枝与株型紧凑。修剪下的枝条晾干伤口 1~2 天后扦插，成活率高。每 1~2 年春季换盆一次，介质以颗粒土为主，保证排水。换盆后可结合修剪重新塑造形态。
