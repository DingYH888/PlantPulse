# 吊兰养护指南

## 概述

吊兰是天门冬科多年生草本，叶片细长呈带状，匍匐茎末端会长出带气生根的小苗。它适应性强、耐半阴，对新手友好，常用于悬挂栽培。吊兰的肉质根能储水，因此耐短期干旱，但怕盆土长期积水和叶心积水。

## 浇水

表土干燥 2~3 厘米后浇透，春秋 5~7 天一次，夏季 3~5 天一次，冬季 10~14 天一次。吊兰的白色肉质根明显增粗时说明水分偏多，应减少频率并检查排水。浇水时尽量沿盆边注入，避免水积在叶心导致腐烂。悬挂栽培的吊兰失水更快，夏季需每周检查两次盆土重量。

## 光照

适合半阴环境，东向窗、北向窗或距南窗 2 米处均可。每天 3~5 小时散射光叶色最鲜亮，金边、银心品种在光照不足时条纹会变淡。夏季避开正午强光，否则叶尖焦枯。长期放在阴暗角落会导致叶片细弱、抽出的匍匐茎减少，可每周移到明亮处补光数天。

## 施肥

生长季 4~9 月每 2~3 周施一次稀薄液肥，浓度取推荐量的一半，氮磷钾均衡即可。金边品种氮肥不宜过多，否则斑纹退化。冬季温度低于 12℃ 时停肥。新上盆或刚分株的植株缓苗 3 周后再开始施肥，避免伤根。

## 温度与湿度

适宜温度 15~25℃，可短暂耐受 5℃ 低温，但长期低于 5℃ 叶片会冻伤发黑。夏季高于 32℃ 时生长放缓，需加强通风。空气湿度 50%~70% 较合适，干燥季节叶尖容易干枯，可喷雾或在水盘上放置湿石子增湿。避免将吊兰放在暖气片正上方。

## 病虫害防治

常见叶尖干枯、根腐和介壳虫。叶尖干枯多因空气干燥或自来水含盐量高，可改用放置一夜的自来水并修剪干尖。根腐表现为叶片发黄发软、盆土有酸臭味，需脱盆剪除烂根、换新介质。介壳虫少量时用酒精棉签擦除，严重时按说明使用吡虫啉。

## 繁殖与换盆

匍匐茎上的小苗长出 3~5 厘米气生根后剪下，直接上盆或水培即可成活。根系拥挤、盆土板结时每 1~2 年换盆一次，新盆比原盆大 3 厘米左右，介质以疏松的园土加珍珠岩为宜。
