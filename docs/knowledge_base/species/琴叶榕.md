# 琴叶榕养护指南

## 概述

琴叶榕是桑科榕属常绿乔木，叶片宽大呈提琴形，叶脉明显，是近年热门的室内大型绿植。它喜光、喜稳定环境，对温度骤变、搬动和浇水不当非常敏感。养护重点是给足光照、避免积水、减少位置变动，否则容易出现大面积落叶。

## 浇水

表土干燥 3~5 厘米后浇透，春秋 7~10 天一次，夏季 5~7 天一次，冬季 15~20 天一次。琴叶榕怕涝胜于怕旱，盆土长期潮湿会导致根腐与落叶。浇水前用竹签检查内部湿度，浇透后倒掉托盘积水并通风。水质偏硬地区建议使用放置过夜的自来水，减少叶面白斑与焦边。

## 光照

喜充足明亮光照，每天 5~6 小时散射或早晚直射最佳，靠近南向、东向窗 0.5~1 米处较理想。光照不足时新叶变小、节间拉长、下部落叶。夏季正午强光可能灼伤叶片，需纱帘过滤。位置一旦固定尽量不移动，频繁改变光照方向会引起应激落叶。

## 施肥

生长季 4~9 月每 3~4 周施一次均衡复合肥，浓度取推荐量的一半。琴叶榕需肥量中等，浓肥会导致叶缘焦枯与根系损伤。秋季补施一次磷钾肥增强抗性。冬季低于 15℃ 停肥。新购或换盆后一个月内不施肥，先让植株适应环境。

## 温度与湿度

适宜温度 18~28℃，低于 12℃ 停止生长，低于 8℃ 易落叶与冻伤。空气湿度 50%~70% 较合适，供暖季与空调房可定期喷雾或使用加湿器。琴叶榕怕冷风直吹与暖气烘烤，应远离门窗缝隙、出风口。温度骤变是叶片突然大量脱落的最常见原因。

## 病虫害防治

叶斑病与锈病在通风不良、叶面积水时易发，表现为褐色或锈色斑点，需剪除病叶、减少喷水、加强空气流通。红蜘蛛在干燥环境繁殖快，叶背出现细密黄点，可冲洗叶背并提高湿度，严重时按说明使用杀螨剂。介壳虫少量时人工擦除即可控制。

## 换盆与整形

每 1~2 年春季换盆一次，盆径增加 3~5 厘米，介质需疏松透气并保证排水。下部叶片自然老化脱落属正常现象，可修剪整形。若植株过高，可在春季短截促发侧枝，剪口涂抹愈合剂防止感染。换盆后缓苗两周内避免强光与施肥。
