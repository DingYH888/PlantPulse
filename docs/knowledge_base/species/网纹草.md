# 网纹草养护指南

## 概述

网纹草是爵床科多年生常绿草本，叶片布满白色、粉色或红色网状叶脉，色彩鲜明，适合制作组合盆栽与桌面微景观。它喜高湿、怕干燥，也怕强光与积水。网纹草的萎蔫速度很快，缺水数小时就会明显下垂，属于"娇气"的观叶植物。

## 浇水

表土略干即需补水，春秋 3~4 天一次，夏季 1~2 天一次，冬季 5~7 天一次。网纹草根系浅而细，盆土不可完全干透，也不可积水。建议用细嘴壶少量多次浇，保持介质均匀湿润。托盘积水必须倒掉。空气干燥时可在盆周喷雾增湿，但避免叶面积水过夜。

## 光照

喜半阴散射光，北向窗、东向窗或距南窗 2~3 米处较理想，每天 2~4 小时柔和光照即可。强光直射会让叶片褪色、叶缘焦枯。光照过弱会导致茎节拉长、叶色暗淡、网纹不鲜明。可每 1~2 周转动花盆，保持株型紧凑均匀。

## 施肥

生长季 4~9 月每 3~4 周施一次极稀薄的观叶液肥，浓度取推荐量的四分之一。网纹草对盐分敏感，浓肥会造成叶尖焦枯。冬季及高温期停肥。施肥后如出现叶缘发黄，应立即用清水透灌稀释，并暂停施肥一个月。

## 温度与湿度

适宜温度 18~26℃，低于 15℃ 生长停滞，低于 10℃ 易受寒害、叶片发黑。空气湿度 70%~85% 最为理想，是养护成败的关键。可使用加湿器、湿石子托盘或玻璃罩保湿，但需定期通风，避免闷湿引发霉病。远离空调出风口与暖气片。

## 病虫害防治

根腐与茎腐多因积水与闷湿引起，需控水、脱盆修根并换透气介质。灰霉病在低温高湿不通风时易发，表现为叶片出现灰褐色霉层，应剪除病叶、加强通风并降低湿度。红蜘蛛在干燥环境易发，可提高湿度并冲洗叶背，严重时按说明使用杀螨剂。

## 修剪与扦插

植株徒长或下部叶片脱落时，可从基部剪短，促进分枝。剪下的茎段保留 2~3 个节点插入湿润介质，约 2 周生根，适合批量补盆。修剪后一周内避免强光与施肥，放在阴凉通风处缓苗。
