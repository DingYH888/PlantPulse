# 天竺葵养护指南

## 概述

天竺葵是牻牛儿苗科多年生草本，花球紧凑、花期长，是阳台与窗台的常见花卉。它喜充足光照、凉爽干燥和良好通风，怕高温高湿与积水。天竺葵夏季高温时容易黄叶、烂茎，需要提前控水降温。

## 浇水

表土干燥 2~3 厘米后浇透，春秋 3~5 天一次，夏季 5~7 天一次且减少水量，冬季 7~10 天一次。天竺葵肉质茎怕积水，浇水应沿盆边注入，避免淋湿叶片与花心。托盘积水必须倒掉。夏季高温时控水并加强通风，冬季保持介质偏干。

## 光照

喜充足光照，每天 4~6 小时直射光最理想，南向、东向阳台均可。光照不足会导致枝条徒长、花量减少、花色变淡。夏季高温时需遮阴 30%~50%，避免叶片灼伤。冬季放在室内向阳处，保持充足光照。定期转动花盆，保持株型匀称。

## 施肥

生长季每 10~15 天施一次稀薄复合肥，浓度取推荐量的一半。现蕾期改用磷钾肥，促进花球饱满。夏季高温超过 32℃ 时停肥，冬季低于 10℃ 时停肥。施肥时避免溅到叶片，肥液残留易引起叶斑。花后补一次薄肥帮助恢复。

## 温度与湿度

适宜温度 15~25℃，高于 30℃ 生长停滞、易黄叶烂茎，低于 5℃ 易受冻害。空气湿度 40%~60% 较合适，天竺葵怕高湿，不需要喷雾。夏季需加强通风、遮阴降温。冬季移入室内向阳处，保持 5℃ 以上并控水。

## 病虫害防治

灰霉病在低温高湿、通风不良时高发，表现为叶片与花梗出现灰褐色霉层，需立即剪除病部、加强通风并降低湿度。茎腐多由积水引起，需控水并换透气介质。蚜虫与红蜘蛛常见，少量时冲洗清除，严重时按说明用药。定期清理枯叶可减少病源。

## 修剪与繁殖

花后剪除残花与过密枝，促进新花枝萌发。徒长枝可短截，保持株型紧凑。扦插繁殖容易，取健康茎段晾干伤口后插入微潮介质，约 2 周生根。每 1~2 年春季换盆一次，介质需疏松透气、排水良好。
## 越夏与越冬

夏季高温是天竺葵最难熬的阶段。气温持续高于 32℃ 时，植株会进入半休眠，应把花盆移到通风阴凉处，减少浇水并停止施肥，避免中午浇水与淋雨。此时不要重剪、不要换盆，等秋季气温回落后再恢复水肥。冬季应移入室内向阳处，保持 5℃ 以上，减少浇水但不可长期干透，室内供暖时注意远离暖气片，避免热风烘烤导致茎干失水。
