# 孔雀竹芋养护指南

## 概述

孔雀竹芋是竹芋科多年生草本，叶片上有深浅相间的羽状斑纹，形似孔雀尾羽，夜间叶片会略微上举。它原产热带雨林下层，喜高湿、散射光和稳定温度，对干燥空气与硬水非常敏感，属于养护要求较高的观叶植物。

## 浇水

表土干燥 1~2 厘米后浇透，春秋 3~5 天一次，夏季 2~3 天一次，冬季 7~10 天一次。竹芋根系细弱，既怕干旱也怕积水，介质应保持均匀微润。建议使用放置一夜的自来水或雨水，硬水中的盐分会导致叶缘焦枯。浇水后倒掉托盘积水，避免根部缺氧。

## 光照

喜半阴散射光，北向窗、东向窗或距南窗 2~3 米处较理想，每天 2~4 小时柔和光照即可。直射光会让叶片迅速褪色、焦边，且斑纹难以恢复。光照过弱则叶色暗淡、斑纹变淡、植株徒长。可每周转动花盆 90 度，保持株型匀称。

## 施肥

生长季 4~9 月每 3~4 周施一次极稀薄的观叶液肥，浓度取推荐量的四分之一。竹芋对肥料盐分敏感，浓肥会造成叶尖与叶缘焦枯。冬季及高温期停肥。施肥前确保盆土微湿，避免干土施肥伤根。新换盆植株一个月内不施肥。

## 温度与湿度

适宜温度 18~27℃，低于 15℃ 生长停滞，低于 10℃ 易受寒害。空气湿度 70%~85% 是理想区间，是竹芋养护的核心。干燥环境需使用加湿器，或把花盆放在铺有湿石子的托盘上，避免盆底直接浸水。远离空调出风口、暖气片与冷窗。

## 病虫害防治

红蜘蛛在干燥环境极易爆发，叶背出现细密黄点与蛛丝，需提高湿度、冲洗叶背，严重时按说明使用杀螨剂。叶斑病与根腐多由高湿不通风或积水引起，应剪除病叶、改善空气流通并控制浇水。介壳虫少量时用酒精棉签清除。定期擦拭叶片便于早期发现问题。

## 换盆与休眠管理

每 1~2 年春季换盆一次，盆不宜过大，介质需疏松保水，可用泥炭混合珍珠岩与少量树皮。竹芋在低温或干燥时会进入半休眠，叶片卷曲、停止生长，此时应减少浇水、停止施肥，等环境改善后重新萌发。不要因休眠误判为死亡而丢弃。
