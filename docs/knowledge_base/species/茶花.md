# 茶花养护指南

## 概述

茶花是山茶科常绿灌木或小乔木，叶片革质光亮，冬春开花，花型端庄。它喜酸性土壤、半阴高湿和凉爽环境，生长缓慢，耐修剪。茶花的花蕾期较长，环境剧变容易导致落蕾，因此"稳定"比"勤快"更重要。

## 浇水

表土干燥 2~3 厘米后浇透，春秋 3~5 天一次，夏季 2~3 天一次，冬季 7~10 天一次。茶花喜湿润但怕积水，介质需排水良好。建议使用雨水或放置过的自来水，避免长期使用碱性水。花蕾期保持介质微润但不积水，过干过湿都会落蕾。托盘积水必须倒掉。

## 光照

喜半阴散射光，每天 3~5 小时柔和光照较理想。春秋可接受早晚直射，夏季需遮阴 50%~70%，强光会灼伤叶片。冬季可放在南向窗台充分见光，有利于花蕾发育。光照过弱会导致枝条细弱、花蕾少、花色淡。花期避免频繁移动花盆。

## 施肥

生长季 4~9 月每 2~3 周施一次稀薄酸性液肥，浓度取推荐量的一半。花芽分化期与现蕾期改用磷钾肥，减少氮肥。每月可补充一次硫酸亚铁维持酸性。夏季高温超过 32℃ 与冬季低于 10℃ 时停肥。忌施浓肥与未腐熟有机肥。

## 温度与湿度

适宜温度 15~25℃，高于 30℃ 生长受阻，低于 5℃ 易受冻害，部分品种可耐短期 0℃。空气湿度 60%~80% 较理想，干燥季节需喷雾增湿。花期温度以 10~15℃ 为宜，温度过高会缩短花期。冬季移入室内向阳处，避免冷风直吹。

## 病虫害防治

炭疽病与叶斑病在高温高湿不通风时易发，表现为叶片褐色斑点，需摘除病叶、改善通风并减少叶面淋水。黄化病多因土壤偏碱缺铁，可补充硫酸亚铁。介壳虫常附着在叶背与枝干，少量时用酒精棉签清除，严重时按说明使用吡虫啉。花蕾期谨慎用药。

## 修剪与换盆

花后剪除残花与过密枝、病弱枝，改善通风并促进新枝。重剪应在花后进行，避免剪除已分化的花芽。每 2 年春季花后换盆一次，介质必须酸性、疏松透气，可用腐叶土混合松针土与珍珠岩。换盆时保留部分原土，减少伤根。
