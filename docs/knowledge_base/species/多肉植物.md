# 多肉植物养护指南

## 概述

多肉植物是一类叶片或茎干肥厚储水的植物统称，包含景天科、番杏科、百合科等多个科属。它们的共同点是耐旱、喜光、怕积水，养护原则高度一致：充足光照、透气介质、干透浇透、良好通风。不同品种的具体需求略有差异，可在本篇基础上参考专属品种文档。

## 浇水

遵循"干透浇透"，盆土完全干燥后再浇，春秋生长季通常 7~10 天一次，夏季高温与冬季低温时 15~30 天一次甚至断水。判断依据为盆土干透、叶片略软但未皱缩。浇水应浇透并迅速排空托盘，避免叶心与叶腋积水。夏季闷热时控水比补水更安全，冬季低温时保持干燥可提高抗寒能力。

## 光照

多数多肉喜充足光照，每天 4~6 小时直射光最利于株型紧凑、叶色鲜艳。光照不足会导致徒长，茎节拉长、叶片变薄下翻。夏季正午极端强光需适当遮阴，避免日灼斑。秋季昼夜温差大时叶色最容易出状态。室内养护应放在南向窗台，并定期转动花盆。

## 施肥

生长季 4~5 月和 9~10 月每月施一次稀薄多肉专用肥，浓度取推荐量的三分之一。多肉需肥量极低，浓肥会造成烧根与徒长。夏季高温与冬季低温时停肥。新上盆或换盆后一个月内不施肥。介质含颗粒较多时，可适当增加微量元素补充。

## 温度与湿度

多数多肉适宜温度 15~28℃，高于 35℃ 或低于 5℃ 时进入休眠，需控水停肥。空气湿度 30%~50% 即可，不需要喷雾，高湿会增加腐烂风险。夏季需加强通风，避免闷热；冬季应移入室内向阳处，保持介质干燥。昼夜温差 8~10℃ 有利于叶色上色。

## 病虫害防治

根腐与黑腐是最主要风险，多由浇水过多、介质不透气引起，表现为茎基发黑变软、叶片透明化。发现后应立即脱盆，切除腐烂部分至健康组织，消毒晾干后换颗粒介质重栽。介壳虫常藏在叶背与叶心，少量时用酒精棉签清除，严重时按说明使用吡虫啉。

## 换盆与繁殖

每 1~2 年春季换盆一次，介质以颗粒为主，如赤玉土、火山岩、粗砂混合少量泥炭。换盆前应晾根 1~2 天，上盆后 3~5 天再浇水。叶插、枝插、分株均可繁殖，取健康叶片或侧芽晾干伤口后放在微潮介质上，约 2~4 周生根发芽。
