# 文竹养护指南

## 概述

文竹是天门冬科多年生攀援草本，枝叶纤细如羽毛，姿态轻盈，适合案头与书房摆放。它喜温暖湿润和半阴环境，根系肉质、不耐浓肥与积水。文竹最常见的失败原因是空气干燥导致黄叶，以及浇水忽干忽湿。

## 浇水

表土干燥 1~2 厘米后浇透，春秋 3~5 天一次，夏季 2~3 天一次，冬季 7~10 天一次。文竹根系偏浅，盆土过干会让细枝迅速失水变黄，过湿则烂根。建议用细嘴壶缓慢浇水，避免冲刷盆土。浇水后保持通风，托盘积水及时倒掉。水质偏碱时可放置一夜再用，减少叶尖发黄。

## 光照

喜半阴，忌强光直射。东向窗台或距南窗 2~3 米处较为理想，每天 2~4 小时柔和散射光即可。直射光会让细叶迅速焦黄脱落，且难以恢复。长期过暗则枝叶稀疏、节间拉长、株型松散。可每周转动花盆，让受光均匀。

## 施肥

生长季 4~9 月每 3~4 周施一次极稀薄的液肥，浓度取推荐量的四分之一。文竹对盐分敏感，浓肥会造成叶尖焦枯甚至整株枯黄。可使用观叶植物专用肥或稀薄饼肥水。冬季及高温期停肥。施肥后如出现叶尖发黄，应浇一次透水稀释并暂停施肥。

## 温度与湿度

适宜温度 15~25℃，低于 5℃ 易受冻，高于 30℃ 且通风不良时容易黄叶。空气湿度 60%~75% 最为理想，干燥季节可每日喷雾周围空气，或在托盘内放置湿石子增湿，但盆底不要直接泡水。远离空调出风口、暖气片和电视等热源。

## 病虫害防治

叶枯病与根腐较常见。叶枯多由空气干燥、强光或肥害引起，需剪除枯枝、改善环境。根腐表现为茎基发黑、盆土有异味，应脱盆剪除烂根并用多菌灵消毒后换土。红蜘蛛在干燥环境下易发，叶背出现细小蛛丝，可冲洗并提高湿度，严重时使用杀螨剂。

## 修剪与换盆

枯黄枝条应从基部剪除，避免残枝消耗养分。株型过高时可短截，促进侧枝萌发。每 1~2 年春季换盆一次，盆不宜过大，介质需疏松透气，可用腐叶土混合珍珠岩。换盆后放在阴凉处缓苗一周，期间不施肥。
