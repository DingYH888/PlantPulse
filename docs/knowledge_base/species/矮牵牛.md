# 矮牵牛养护指南

## 概述

矮牵牛是茄科多年生草本，常作一二年生栽培，花量大、花期长，是阳台与花坛的主力花卉。它喜充足光照和水肥，生长迅速、分枝多。矮牵牛的关键是打顶促分枝、充足光照与规律施肥，否则容易徒长、花量稀疏。

## 浇水

表土干燥 1~2 厘米后浇透，春秋 1~2 天一次，夏季每天一次甚至早晚各一次，冬季 3~5 天一次。矮牵牛叶片多、蒸腾强，缺水时叶片迅速萎蔫。浇水应浇透，盆底排水必须通畅，托盘积水倒掉。夏季高温时避免正午浇水，可在早晚进行。花期避免大水冲刷花朵。

## 光照

喜充足光照，每天 5~6 小时直射光最理想，南向阳台或露台最佳。光照不足会导致枝条徒长、花量减少、花色变淡。夏季高温时正午可适当遮阴，避免花朵灼伤。冬季放在室内向阳处。定期转动花盆，让各侧受光均匀，保持株型饱满。

## 施肥

生长季每 7~10 天施一次稀薄液肥，浓度取推荐量的一半。苗期偏氮促进枝叶，现蕾后改用磷钾肥促进开花。持续开花期需规律追肥，可使用水溶性肥随浇水施用。夏季高温超过 35℃ 时停肥。施肥后浇一次清水，避免盐分积累。

## 温度与湿度

适宜温度 15~28℃，高于 35℃ 生长受阻、花朵变小，低于 5℃ 易受冻害。空气湿度 50%~70% 较合适，高湿不通风时易发灰霉病。夏季需加强通风。冬季移入室内向阳处，保持 10℃ 以上可继续开花，温度过低则逐渐枯萎。

## 病虫害防治

灰霉病在低温高湿、通风不良时高发，表现为花朵与叶片出现灰褐色霉层，需剪除病部、加强通风并降低湿度。白粉病在干燥闷热时易发，叶面出现白色粉层，可改善通风并使用对症药剂。蚜虫与红蜘蛛常见，少量时冲洗清除，严重时按说明用药。

## 打顶与修剪

苗高 8~10 厘米时进行第一次打顶，保留 4~6 片叶，促进侧枝萌发；侧枝长到 6~8 厘米时可再次打顶，一般 2~3 次，形成饱满株型。花后剪除残花与过长枝条，可促进二次开花。垂吊品种可适当修剪整形。每 1 年更换新土，避免连作病害。
