# 水仙花养护指南

## 概述

水仙花是石蒜科球根花卉，冬春开花、清香淡雅，是传统的年宵花。中国水仙多采用水培，只需清水与光照即可开花，养护简单。水培水仙的关键是保持水质清洁、给予充足光照并控制温度，避免叶片徒长倒伏。

## 浇水

水培水仙每 2~3 天换一次清水，保持水位淹没种球底部三分之一左右，不要将整个种球泡在水中。换水时清洗容器与根系黏液。土培时表土干燥 1~2 厘米后浇透，3~5 天一次，忌积水。开花期可适当减少换水频率，保持水质清洁即可。

## 光照

喜充足光照，每天 4~6 小时直射或明亮散射光。光照不足会导致叶片徒长、叶片软倒、开花少且花色淡。水培初期可放在阴凉处促进生根，生根后移到向阳窗台。开花期给予充足光照可延长花期。每天转动容器，让植株受光均匀，避免偏向生长。

## 施肥

水培水仙通常不需要施肥，种球自身储存的养分足以支撑一次开花。若叶片偏黄、长势弱，可在开花前每月加入一次极稀薄的水培营养液，浓度取推荐量的四分之一。土培时可在种植时混入少量骨粉作底肥，生长期不额外追肥。花后不施肥。

## 温度与湿度

适宜温度 8~15℃，温度越低花期越长，高于 20℃ 生长过快、叶片徒长、花期缩短。水培环境本身湿度较高，不需要额外喷雾。冬季应放在向阳但不太暖的位置，避免靠近暖气片。夜间可适当降低温度，保持昼夜温差，有利于株型紧凑。

## 病虫害防治

水培水仙最常见的问题是种球腐烂与水质变差，表现为种球发软、水有异味，需立即换水、清除腐烂部分并保持水位适中。叶片徒长倒伏多因光照不足与温度过高，可通过增加光照、降低温度改善。蚜虫偶发，可用清水冲洗。种球有轻微霉斑时可用多菌灵处理。

## 花后处理

花谢后剪除残花，保留叶片继续水培或转土培，让养分回流种球。家庭水培种球通常难以复花，多数作为一次性栽培。若希望复花，花后可转土培，保持充足光照与水肥，叶片枯黄后挖出种球，储存在阴凉干燥处越夏，秋季重新栽种。
