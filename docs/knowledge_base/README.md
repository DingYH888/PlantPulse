# 知识库文档目录（RAG 数据源）

本目录是 PlantPulse AI 养护建议的**唯一知识来源**（PRD 8.1 节点3）。
把整理好的养护文档放进这里，执行一次入库脚本即可被检索。

## 1. 放哪里

```
PlantPulse/
├─ docs/
│  └─ knowledge_base/        ← 文档放这里（支持子目录）
│     ├─ species/            ← 品种专属养护（推荐）
│     │  ├─ 绿萝.md
│     │  └─ 龟背竹.md
│     └─ general/            ← 通用养护知识（推荐）
│        └─ 通用养护基础.md
└─ backend/
   └─ chroma_db/             ← 向量库自动生成，不需要手动维护
```

- 直接放 `docs/knowledge_base/` 根目录也可以，但**推荐按 `species/` 与 `general/` 分类**：
  - `species/`：品种专属知识，检索时优先命中，回答可标注来源；
  - `general/`：通用知识，品种无专属文档时作为降级来源（节点3b）。
- `README.md`、`_template.md` / `_template.txt` 与隐藏文件不会入库，其余文件（包括其他 `_` 开头的文件）都会入库。

## 2. 支持格式

| 格式 | 说明 |
|---|---|
| `.md` / `.markdown` | **首选**，可用 frontmatter 标注元数据 |
| `.txt` | 纯文本，UTF-8 编码（兼容 GBK） |
| `.pdf` | 按页提取文本，扫描件（无文字层）无效 |
| `.docx` | 提取段落与表格文本 |

## 3. 推荐文档结构（frontmatter 可选）

```markdown
---
doc_id: monstera-care-001
title: 龟背竹养护指南
species: 龟背竹
aliases: 龟背竹, Monstera deliciosa, 蓬莱蕉
category: species
---

# 龟背竹养护指南

## 浇水
...

## 光照
...

## 施肥
...

## 温度与湿度
...

## 病虫害防治
...
```

字段说明：

| 字段 | 必填 | 作用 |
|---|---|---|
| `doc_id` | 否 | 引用来源 ID，不填时按“目录+文件名”自动生成，建议英文短横线 |
| `title` | 否 | 前端“参考来源”展示标题，不填用文件名 |
| `species` | 否 | 标准品种中文名，用于检索 Query 拼接与来源标注 |
| `aliases` | 否 | 同义词/学名，逗号分隔，用于品种归一化（节点2） |
| `category` | 否 | `species`（品种专属）或 `general`（通用）；不填时按目录名推断 |

**不写 frontmatter 也能入库**，系统会按文件名与所在目录尽力推断；
但写了 `species` / `category` 后检索准确率会明显更高。

## 4. 内容要求（影响回答质量）

1. **一个品种一个文件**：不要把多个品种混在一篇；文件名使用标准品种中文名（如 `绿萝.md`）。
2. **按养护主题分节**：建议覆盖 `浇水 / 光照 / 施肥 / 温度与湿度 / 病虫害防治` 五个主题，
   与 AI 输出分节一一对应（PRD FR-403）。
3. **单篇 800~3000 字**：过短信息量不足，过长会被切成多个片段、检索易分散。
4. **每段聚焦一个主题**：一个段落只讲一件事，避免“什么都聊一点”，便于 600 字切片命中。
5. **使用陈述句与区间表述**：如“表土干燥后浇透”，避免“必须每天浇 200ml”这类绝对指令。
6. **品种名统一**：全文使用同一标准名，别名写进 `aliases`。
7. **不要放入**：用户隐私数据、未授权转载的付费内容、与养护无关的营销文案、扫描版 PDF。
8. **可以放英文资料**：但建议附中文摘要，LLM 输出仍为中文。

## 5. 入库与更新

文档放好后，在 `backend` 目录执行（需已安装 `requirements-ai.txt`）：

```bat
..\.venv\Scripts\python.exe -m scripts.ingest_knowledge
```

- 默认增量入库：以文件路径为业务主键，**新增/修改的文件会自动覆盖旧向量**；
- 知识库结构大改（大量删除/重命名）时使用重建：

```bat
..\.venv\Scripts\python.exe -m scripts.ingest_knowledge --rebuild
```

- 只入库指定目录：

```bat
..\.venv\Scripts\python.exe -m scripts.ingest_knowledge --dir ..\docs\knowledge_base\species
```

## 6. 切分与检索参数（.env 可调）

| 参数 | 默认 | 说明 |
|---|---|---|
| `RAG_CHUNK_SIZE` | 600 | 回答散乱/抓不住重点时调小（如 400） |
| `RAG_CHUNK_OVERLAP` | 100 | 建议为 chunk_size 的 10%~20% |
| `RAG_TOP_K` | 3 | 每次注入 LLM 的文档数（实测 3 条可覆盖品种 + 急救） |
| `RAG_SCORE_THRESHOLD` | 0.55 | 低于阈值的切片丢弃；实测绿萝品种文档 0.636、通用急救 0.591 |

> 2026-10-28 基于 60 个品种 / 137 条切片实测调优：`top_k=3`、阈值 `0.55`。
> PRD 原始默认值为 5 / 0.45，如知识库扩充后召回不足可回退。

修改后重启后端即可生效，无需重新入库（切分参数变更才需要重建向量库）。
